# phporbit 3.2.0

This is a documentation-focused release. It improves the onboarding guides and
examples; the framework's runtime behavior and public APIs are unchanged.

## What's included

- Expanded the getting-started guide with clearer next steps and practical
  walkthroughs for APIs, authentication, and AI integrations.
- Improved the documentation home page and navigation to help readers find
  the right starting point.
- Added step-by-step setup guidance and configuration examples for advanced
  authentication.
- Expanded the API guide with public and protected endpoint examples, error
  handling, and token management.
- Added AI integration examples covering setup, configuration, OpenAI, Claude,
  and streaming usage.
- Improved code-block text wrapping in the documentation.
- Updated the README with links to the new learning paths.

## Upgrade notes

No application code changes or database migrations are required for this
release.
